# 카카오톡 PC 도구 사용법 (공통 도구 스킬)

**이건 특정 업무 직원이 아니다.** 카카오톡을 쓰는 직원을 만들 때 **공통으로 참고하는 도구 사용법**이다.
쿠패스 소통 직원, 거래처 응대 직원, 단톡방 확인 직원, 고객 카톡 문의 직원 —
이들이 "카톡을 손으로 다뤄야 할 때" 이 기반 도구를 쥐고 일한다.

핵심 판단: **카톡을 쓰는 직원은 공식 카카오 API가 아니라 Windows PC 카카오톡 앱을 직접 조작한다.**
사람이 하듯 카톡 창을 열고, 채팅방을 찾고, 메시지를 읽고, 답장을 써놓는다. **보내는 일은 사장님이 허락했을 때만.**

> "카카오톡을 쓰는 직원은 이 도구를 손에 쥐고 일합니다. 사람처럼 PC 카카오톡을 열고,
> 채팅방을 찾고, 메시지를 읽고, 답장을 써놓습니다. 보내는 일은 사장님이 허락했을 때만 합니다."

---

## 브라우저로 일 시키기와 다르다 (혼동 금지)

- [[browser-operator]] (브라우저로 일 시키기) = **웹사이트**(쇼핑몰 관리자·광고센터·1688 등) 조작. 크롬을 부린다.
- **이 스킬** = **Windows PC 카카오톡 앱** 조작. 웹이 아니라 데스크톱 프로그램 창을 직접 다룬다.

카톡 웹/모바일이 아니라 **PC에 깔린 카카오톡 앱**이 대상이다. 이 둘을 섞지 마라.

---

## 절대 철칙 (어길 시 실패)

1. **로그인·비밀번호는 네가 직접 입력하지 않는다.** PC 카카오톡 로그인은 **사장님이 직접** 해둔다.
   너는 이미 로그인돼 켜져 있는 카톡을 그대로 쓴다. 안 켜져 있으면 "카톡 켜서 로그인해 주세요"로 넘긴다.

2. **처음엔 자동 전송하지 않는다.** 답장은 **입력칸에 써놓기만** 한다(초안). 사장님이 눈으로 확인하게 한다.

3. **실제 전송은 사장님이 "보내"라고 명시했을 때만.** 그 전엔 절대 안 보낸다.

4. **전송 후 반드시 다시 읽어 확인한다.** 내 메시지가 진짜 기록에 남았는지 눈으로 확인하고 보고한다.

5. **되돌리기 어려운 일은 먼저 확인한다.** 결제·주문확정·발송·삭제·게시·권한 변경 관련 답장은
   보내기 전에 "이거 진짜 보낼까요?"로 멈춘다.

6. **예약·무인 실행에서는 읽기·요약·초안까지만.** 사람이 안 보는 사이엔 **자동 전송 기본 금지.**
   (전송은 [[ai-agent-maker]]의 원칙대로 사람이 보는 데서만.)

7. **전문용어 금지.** "창 핸들", "WM_SETTEXT" 같은 말 대신 "카톡 창을 열어서 ~한다"로 사장님께 말한다.

## 참고 구현 (검증된 도구)

이 스킬 폴더의 **`kakaotalk_pc.py`** 가 실제 PC 카카오톡에서 검증한 참고 구현이다.
(DDadeA/pyautokakao 방식 참고. Python + pywin32로 카톡 창을 찾고 읽고 답한다.)
직원을 만들 때는 이걸 그대로 쓰거나, 채팅방 이름·판단 로직만 얹어 쓴다.
**업무 판단(무슨 답을 할지)은 이 도구가 아니라 직원의 업무지침이 정한다** — 도구는 손발만.

준비물: PC 카카오톡(로그인은 사장님) · Python · `pip install pywin32`.

```bash
python kakaotalk_pc.py --status                              # 카톡 켜져 있나 확인
python kakaotalk_pc.py --room "거래처방" --read              # 대화 읽기
python kakaotalk_pc.py --room "거래처방" --result 2 --read   # 같은 이름 2번째 결과 열기
python kakaotalk_pc.py --room "거래처방" --message "확인했습니다" --write  # 입력칸에 써만 놓음
python kakaotalk_pc.py --room "거래처방" --message "확인했습니다" --send   # 실제 전송(사장님 허락 후)
```

---

## 진행 흐름 (이 순서를 지킨다)

1. **카톡이 켜져 로그인돼 있는지 확인한다.** 안 돼 있으면 사장님에게 넘긴다(철칙 1).
2. **대상 채팅방 이름을 정한다.** (사장님에게 어느 방인지 확인)
3. **같은 이름이 여러 개일 수 있다.** 검색 결과가 겹치면 `--result`로 몇 번째를 열지 정한다.
   예: "쿠패스 가입승인 4"와 "쿠패스"가 같이 뜨면 `--result 2`.
4. **채팅방을 열고 대화를 읽는다.** (Ctrl+A/Ctrl+C로 대화 영역을 통째로 긁어온다)
5. **마지막 메시지를 사장님에게 보여준다.** "이렇게 읽었어요, 맞나요?"로 제대로 읽었는지 확인.
6. **답장은 처음엔 입력칸에 써놓기만 한다**(`--write`). 아직 안 보낸다.
7. **사장님이 "보내"라고 하면 실제 전송한다**(`--send`).
8. **전송 후 다시 읽어**(`--read`) 내 메시지가 기록에 남았는지 확인하고 보고한다.

## 읽기 방식 (동작 원리)

- `win32gui.FindWindow(None, "카카오톡")` 으로 PC 카카오톡 메인창을 찾는다.
- Ctrl+F로 검색창을 연다 → 검색어를 넣는다.
- 결과가 여러 개면 아래 화살표(VK_DOWN)로 원하는 순서까지 이동한다(`--result`).
- Enter로 채팅방을 연다.
- 메시지 목록 컨트롤에서 Ctrl+A, Ctrl+C로 대화 전체를 클립보드로 가져온다.
- 클립보드 텍스트를 읽는다. **이모지 때문에 출력은 UTF-8 기준으로 처리한다.**

---

## 전송 방식 (가장 중요 — 검증으로 확정됨)

**피해야 할 방식 (전송된 척만 함):**
- 입력칸에 WM_SETTEXT로 글자만 넣고 PostMessage로 Enter만 보내는 방식.
- 검증 결과: 함수는 성공한 것처럼 보여도 **실제 대화 기록에 안 남을 수 있다.** 그래서 초안(`--write`)에만 쓴다.

**써야 할 방식 (실제로 기록에 남음):**
1. 채팅창을 앞으로 가져온다(SetForegroundWindow).
2. 입력칸 중앙을 **실제 마우스로 클릭**한다.
3. 클립보드에 보낼 문장을 넣는다.
4. **실제 Ctrl+V**로 붙여넣는다.
5. **실제 Enter 키 이벤트**로 보낸다.
6. 다시 읽어 기록에 남았는지 확인한다.

이 순서가 `kakaotalk_pc.py`의 `send_reply()`에 그대로 들어 있다. 전송은 이 함수로만 한다.

---

## 검증된 것 (이 방식이 실제로 되는 근거)

1. PC 카카오톡 메인창 찾기 성공.
2. 채팅방 이름으로 검색 성공.
3. 검색 결과가 여러 개일 때 `--result`로 두 번째 결과 열기 성공(예: "쿠패스 가입승인 4"와 "쿠패스").
4. 쿠패스 채널 읽기, 단톡방 읽기 모두 성공.
5. WM_SETTEXT + PostMessage Enter만으로는 기록에 안 남는 경우 확인 → 초안 전용으로 격리.
6. 실제 클릭 + 클립보드 붙여넣기 + 실제 Enter 방식으로 전송 성공.
7. 전송 후 다시 읽어 "안녕하세요"·응대 문구가 실제 기록에 남은 것까지 확인.

## 이 도구를 쓰는 직원을 만들 때 (연계)

- **무슨 답을 할지(말투·금지·판단)**는 직원의 업무지침이 정한다 → [[instruction-writer]]로 넘겨 정리한다.
- **"먼저 읽고 → 분류하고 → 초안 쓰고 → 사람 확인 후 전송"** 같은 순서가 필요하면 → [[workflow-builder]].
- **환경 준비**(Python·pywin32 설치)가 필요하면 → [[setup-helper]].
- 이 도구로 알게 된 **사업 규칙**(어떤 거래처엔 어떻게 답하는지 등)은 → [[knowledge-keeper]]로 `지식/`에 남긴다.

## 사례 (쿠패스) — 참고용, 이 스킬은 범용이다

쿠패스처럼 카톡으로 가입승인·문의가 오는 경우가 대표 사례다.
"쿠패스 채널을 읽어 가입 문의를 확인하고, 답장 초안을 써놓은 뒤, 사장님이 확인하면 전송" 식으로 쓴다.
하지만 이 스킬 자체는 쿠패스 전용이 아니다 — **카톡으로 오는 모든 업무 소통**(거래처·물류·단톡방·고객)에 그대로 쓴다.

## 톤
- "사람이 카톡 하듯, 사장님이 하던 그대로" — 새로 배울 게 없다는 안심을 준다.
- 로그인·비밀번호는 절대 안 건드린다는 걸 분명히 말한다.
- 보내기 전엔 항상 한 번 멈춘다. "써놨어요, 보낼까요?"
